# SmartPantryManager

## Project Overview
SmartPantryManager is an Android application designed to help users manage pantry ingredients, monitor expiry dates, and reduce food waste.

## Features
- **Add Ingredients:** Save ingredients with their names, quantities, units, and expiry dates.
- **View Pantry:** Display ingredients stored in the pantry.
- **Edit Ingredients:** Update ingredient information.
- **Delete Ingredients:** Remove ingredients from the pantry.
- **Expiry Warnings:** Identify ingredients that are approaching their expiry dates using colour-coded warnings.
- **Expiry Notifications:** Receive notifications about ingredients that are expiring soon.
- **Notification Settings:** Enable or disable expiry notifications.
- **Recipe Suggestions:** Explore recipe ideas and view recipe details.

## Technologies Used
- Java
- XML
- Android Studio
- SQLite Database
- WorkManager for scheduled expiry checks

## Database
The application uses SQLite to store pantry ingredients locally on the device.

## Purpose
The purpose of SmartPantryManager is to help users organise their pantry, keep track of food expiry dates, and make better use of available ingredients.
